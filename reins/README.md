# REINS土地探し(毎日運用・KRF土地探しとは別ライン)

既存の「土地探しタスクの必須ルール」(IRESシート+Gmail)とは独立。REINSを毎日確認する。

## 対象エリア(6市)
千葉県松戸市 / 東京都東村山市 / 千葉県柏市 / 千葉県船橋市 / 千葉県流山市 / 埼玉県三郷市
(2026-10-25 今宮さん確認: 6市で確定)

## 価格・面積条件(いずれかに該当)
- A: 土地180㎡以上 かつ 4,000万円以下
- B: 土地130〜160㎡ かつ 700万円以下
- C: 土地200㎡以上 かつ 1,000万円以下(確認済み)

## 必須条件
- 整形地(四角い土地)・間口5m以上(確認済み)
- 前面道路幅員4m以上
- 駅徒歩20分以内
- 坪単価90万円で建築した場合の利回り9%以上

## ボリューム方針(2026-10-25 確認済み)
- 木造2階建てまたは3階建て。諸費用7%
- 1フロア2〜5室のどのパターンでも可。**いずれかで利回り9%以上になれば合格**(坪90万円)
- 建蔽率/容積率 50%/100%などの低い物件が中心の想定。住戸15㎡以上
- 整形地かどうか不明な場合は登記簿図書館で公図・地積から確認、図面がなければ面積から概算

## 閲覧方法
今宮さんのローカルPCのブラウザ連携(ログイン済みREINS画面を操作)

## 目標
各市10物件ずつ候補をピックアップ(6市×10=60件)。

## ツール
`python3 tools/reins_screen.py 面積㎡ 価格万円 建蔽% 容積% 賃料円/戸 [階数]`
